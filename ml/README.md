# ml

Machine learning algorithms for flood risk prediction, feature attribution, and uncertainty calibration.

Modules:
- `ml/risk_model/baseline/`: Simple, transparent baseline model (**Phase 17**).
- `ml/risk_model/gradient_boosting/`: Advanced gradient boosted model with SHAP explanations (**Phase 18**, **Phase 19**).

*Note: As defined in the Project Constitution, gradient boosting must use `ml/risk_model/gradient_boosting/` to avoid shadowing external packages.*
